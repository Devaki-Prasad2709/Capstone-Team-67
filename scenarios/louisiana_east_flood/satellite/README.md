# Satellite assets

`pair.json` pins the real SpaceNet 8 Louisiana-East tile `2_23_44`, including
filenames, footprints, sizes, SHA-256 checksums, and official reference counts.
The raw GeoTIFFs remain on the dataset drive and are deliberately not committed.

Set `SPACENET8_DATASET_PATH` to the extracted
`Spacenet8_Louisiana-East_Trainingtar` directory. The registered pre-event,
post-event, and annotation paths are relative to that directory.
